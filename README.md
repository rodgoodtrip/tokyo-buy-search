# Tokyo / Yokohama Buy Search

Public single-page app mirroring the Cursor canvas: sortable table, track/type/line filters, view modes, star/strike (saved per browser via `localStorage`).

## Live site (GitHub Pages)

After Pages is enabled on `main` / root:

`https://<your-username>.github.io/tokyo-buy-search/`

## Local

Open `index.html` in a browser (no build step).

## Data

- `listings.json` / `listings.csv` — same 187 listings
- Stars/strikes are **per visitor browser**, not shared globally
